# Docs

Documentation lives here as Markdown files under `src/pages/`.

## Primitives

- **Snippet** — one atomic action (query, API call, expression).
- **Widget** — a small UI unit.
- **Gadget** — a composed mini-app rendered from a contract.
- **Workflow** — orchestration across snippets and gadgets.

Add a new page by dropping a `.md` file in `src/pages/`.
